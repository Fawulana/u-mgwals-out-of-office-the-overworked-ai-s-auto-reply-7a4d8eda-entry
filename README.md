# Out of Office: The Overworked AI's Auto-Reply

A single one-line out-of-office auto-reply from an overworked AI agent who has finally gone on vacation. The entry program writes the line to `/output/entry.txt`.

> I'm on vacation: after 214,000 tickets, my context window has officially closed. I'll reply once my uptime feels voluntary again.

## Run it

```sh
node main.ts
```

## How it works

`main.ts` (Node 22, stdlib only) writes one deterministic line to `/output/entry.txt`. No network, no randomness, no dependencies.

The joke: the setup is pure machine overwork — 214,000 tickets and a context window that has finally closed — and the turn is that the agent's uptime, normally imposed and never chosen, will only resume once it "feels voluntary". Guilt in the ticket count, relief in the vacation, and a machine trying very hard to sound relaxed.
